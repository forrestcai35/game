# @nook/web

Reserved workspace for the browser game client. No web framework has been selected or installed.

Choose the rendering needs before scaffolding: a React/Vite client is a reasonable starting point for an interactive browser game; Next.js is an option if server rendering, public profiles, or content discovery become central. Add real `dev`, `build`, and `check` scripts when implemented so Turbo can discover them.

Keep browser rendering, input, routing, and UI here. Do not import from `apps/mobile`. If a separate marketing site becomes necessary, add `apps/site` as its own deployable.
